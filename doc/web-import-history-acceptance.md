# Web 导入反馈、会话历史与中键关闭 · 2026-10-16

台账：dev-board#1300 / #1301 / #1303；本机目录清理另记 #1302。

## 修复边界

用户报告空态 Import DOCX 选择本机文件后没有反应。源码确认原流程在 `arrayBuffer()`、ZIP 校验和 IndexedDB 写入期间无任何状态；只有打开引擎时才显示忙状态。失败仅显示短暂 toast，文件输入仅在成功时清空，所以再次选同一失败文件不会触发 change。读取期间也未锁住项目/其他导入，可造成异步交叉。未获得用户当时选择的原始文件，不能断言其具体格式或云盘状态就是根因。

新流程在读取前同步显示文件名和阶段，FileReader 报告真实读取字节；校验、持久化、打开用不确定进度。读取可取消且有 60 秒截止；10 秒后显示慢速及云盘下载提示。错误持续可见并提供重试，选择框立即重置；打开失败时重试复用已创建文件，避免重复导入。项目切换清除旧项目重试入口。完成只在实际打开和标签持久化之后显示。初始空工作区的 Preparing 状态也归一为 No document。

AI 历史以项目为范围存入浏览器 IndexedDB：迁移旧 chat 设置，写入新记录成功后清空旧 key；新会话保留旧记录，可切换、重命名、确认删除并刷新恢复。保留消息关联文档及费用回执，异步费用更新绑定原会话，不能覆盖新消息或复活已删除对话。删除不删除文档，不撤销文档修改或费用。不提供跨浏览器/设备同步。

中键使用真实 auxclick 并阻止默认自动滚动，复用 closeFile 的保存屏障；忙状态不关闭文档。
