# growth/ — 营销与裂变资产

本目录承载官网仓的营销职能（dev-board#329）：宣发方案、裂变打法沉淀、增长活动档案。
**代码不放这里**——「法人格」测试等增长功能的实现照常走 `app/` + `lib/`
（内容文案在 `lib/quiz-data.ts`，与徽章 `BADGE_DEFS` 同一惯例）。

```
growth/
├── playbooks/    # 可复用打法：裂变共性定律、微信红线清单、渠道打法
└── campaigns/    # 一次一档的宣发方案（含复盘）
```

## 全目录通用红线（任何活动开工前先读）

1. **绝不做利诱分享**：分享解锁 / 分享得奖励 / 助力砍价一律禁止（微信封禁头号死因，
   也是 `lib/badges.ts` 的既有不变式）。
2. **测试/裂变内容不进微信 webview**：微信 UA 只见引导页，主站域名不赌连坐封禁。
3. **法律人自嘲只嘲苦劳，不贬损能力**：可以穷/秃/加班，不能暗示水平差、靠关系。
4. **合规卫生**：命名先查商标；娱乐向测试标注「仅供娱乐、非心理学测评」；
   文案避开「包赢」类违反律师执业宣传规范的表述；用户输入最小化收集。

## 数据

增长转化埋点沿仓内惯例落 `data/*.jsonl`（`quiz-events.jsonl`、`cert-scans.jsonl`、
`start-refs.jsonl`）。「法人格」的北极星三率：完成率（visit→complete）、
保存率（complete→download）、回流率（from=qcard 的 visit 占比）。
